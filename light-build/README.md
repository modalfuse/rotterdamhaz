# Light build

The result tables in `work/fit/`, `work/sens/`, `work/cv/` and `work/vot_sens/` correspond to the with-toll calibration at the root of this package.

The no-toll column of Appendix B is `appendix-b/no-toll-calibration_sites.csv`. It comes from the calculation whose fitted total is 934 times 10^4 t/year. It is not `work/vot_sens/run/no_toll/`.

Running these scripts requires `hazbench` unpacked from `code/rotterdamhaz-code-v1.1.0.tgz`.
